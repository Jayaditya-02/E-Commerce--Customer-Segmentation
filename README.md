# E-Commerce Online Customer Segmentation for Smart Incentive System

## 1. Project Overview
This project aims to analyze e-commerce customer purchasing behaviour and group customers into different segments using RFM Analysis and K-Means Clustering. Based on customer segments, the system provides personalized incentives to improve customer engagement and retention.

## 2. Objectives
- Analyze customer purchasing patterns.
- Calculate Recency, Frequency and Monetary (RFM) values.
- Identify customer groups using K-Means Clustering.
- Understand customer behaviour through data visualization.
- Recommend personalized incentives for different customer segments.

## 3. Dataset
The project uses the UCI Online Retail II dataset, which contains online retail transaction records from a UK-based retail store.

## 6. Methodology
RFM Analysis evaluates customers based on:
- Recency: How recently a customer purchased.
- Frequency: How often a customer purchased.
- Monetary: How much a customer spent.

K-Means Clustering groups customers with similar purchasing behaviour.

## 7. Smart Incentive System
Based on customer segments, the system recommends suitable incentives such as:
- Discounts
- Loyalty rewards
- Special offers
- VIP benefits
